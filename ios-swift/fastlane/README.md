# Legacy OshiReader+ release metadata

This directory is retained only for critical maintenance releases of
`com.otterpia.oshireader.plus`. New feature and paid-push development belongs
in the `oshireader-local` repository.

The Fastlane lanes require `APP_STORE_CONNECT_KEY_ID`,
`APP_STORE_CONNECT_ISSUER_ID`, and `APP_STORE_CONNECT_KEY_PATH`.
